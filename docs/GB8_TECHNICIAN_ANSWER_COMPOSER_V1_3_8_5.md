# GB8 Technician Answer Composer v1.3.8.5

## Purpose
Keep the everyday technician answer minimal while retaining complete provenance on demand.

## Default visible output
- No internal recurring-group IDs.
- No serial counts.
- No repair-log counts.
- Findings and historically motivated checks remain concise and readable.

## Evidence mode
Use `--show-evidence` or `:evidence on` to display recurrence counts, representative log numbers, robot serial numbers, Traveler text, and source paths.

## Authority
Frozen source JSON remains authoritative. The composer does not search the corpus, modify recurrence, approve facts, or write Qdrant.
