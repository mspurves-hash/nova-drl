# DRL Terminology Schema v1.5.2

Each glossary entry contains:

- `raw_term`
- `normalized_meaning`
- `category`
- `scope`
- `status`
- `preserve_raw`
- `aliases`
- `notes`

Each terminology annotation records:

- exact text found in the approved value
- raw glossary term
- normalized meaning
- character offsets
- category and scope
- preserve-raw requirement

Terminology is metadata. It is not a repair fact by itself and does not
replace human-approved wording.
