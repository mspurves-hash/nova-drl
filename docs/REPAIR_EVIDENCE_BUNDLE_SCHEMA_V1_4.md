# Repair Evidence Bundle v1.4 — Core Fields

Each repair-event bundle contains:

- serial metadata
- log number, repair date and daily sequence
- warranty status
- missing-traveler status
- original evidence files
- file role and evidence authority
- text-extraction status and source-linked extracted text
- existing Traveler Reader derived artifacts
- evidence completeness heuristic
- explicit evidence gaps
- `accepted_as_repair_summary: false`

The bundle is an evidence dossier, not a final diagnosis.
