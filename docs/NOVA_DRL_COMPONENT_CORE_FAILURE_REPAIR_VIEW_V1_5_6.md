# NOVA DRL v1.5.6 - Engineer Product View

For recognized product searches, the normal engineer report is intentionally concise:

1. Tracking / project identifiers
2. Base equipment/product identity
3. Parts Replaced - vertical `Part Number | Times Replaced`, component-core consolidated
4. Reported Failure - top recurring customer-provided failures (`Notes: FA - ...` and structured complaint evidence)
5. Technician Repair History - top recurring work actually performed
6. Source files

Administrative/database notes remain searchable metadata but do not populate Technician Repair History.
Testing/verification remains separate evidence and is not presented as repair work.
